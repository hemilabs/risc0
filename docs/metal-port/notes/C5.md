## Deviations / decisions

- **Mutex, not RefCell**, for `scratch` (PLAN 4.3 says RefCell): with a RefCell the circuit HAL is
  `!Sync` and `Arc<MetalCircuitHal>` fails `clippy::arc_with_non_send_sync`; rv32im's R7 HAL made the
  same choice. Uncontended, so no cost.
- **Eval PSOs lazy** (C4's issue to C5): `MetalHal::load_library` builds every listed PSO, so loading
  `METAL_KERNEL_NAMES` would pay both eval variants (~70 s cold) on the first lift even though C5's
  eval_check is still CPU. Base kernels load eagerly with `MetalKernels::new(device, ..)` (no lock),
  the selected eval variant on first `eval_kernels()` or in `warmup()`.
- The recursion PSO cache is process-wide on the first device, like F0's zkp cache and R7's.
- `host_chains_backend()` is a runtime `fn` (not a build-script cfg), because `build.rs` is not
  C5's file and the metal answer depends on `enabled("recursion")`. Under metal, host chains are now
  computed in `prepare()` (and on the proving thread when absent) but **ignored by C5's CPU-delegated
  witgen** (cost: a few ms of host time per proof; also for p254 which runs on the CPU prover). C6
  makes them useful.
- `Prover::run`/`prewarm` take `metal::exclusive()` for the whole proof, mirroring CUDA. The CPU
  circuit phases then run under the GPU lock (as they would on CUDA's stream). They do not call the
  HAL from rayon/poolstl workers, so F0's rayon deadlock does not apply.

## Known gaps

- All three circuit phases are CPU (by design for C5); `upload_host_witness` keeps the trait default
  (`bail!`; only intel prewitgen uses it — C6 per errata 8.4); `has_row_passes` false.
- The zkvm side does not call `risc0_circuit_recursion::prove::start_metal_warmup()` yet (zkvm
  `prover_impl.rs` is not C5's file).
- `test_recursion_host_chains_check` is still ignored on metal (zkvm tests file, C9). With C5 it would
  pass trivially (the CPU witgen ignores the chains), so it should stay ignored until C6.
- No real GPU fault exercised (no Metal kernel dispatched by C5); `fault_word`/`check_fault` are
  tested by a host write.
