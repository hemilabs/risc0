## What was done

  - the reject diagnostics are the expected ones;
  - the extern pair links, and the use-only `.air` fails with `Undefined symbol`;
  - `assert` preprocesses to `((void) 0)`.
- `probes/README.md`: one row per probe with result, numbers and the exact runner command. This is the deliverable for other agents.

## Key findings for other items
- Dynamic threadgroup memory > 32768 runs silently up to 64 KB and corrupts data at 128 KB, with status `Completed` in both cases. The host assert is mandatory (F0). A static 36 KB array fails cleanly at PSO creation.
- Pointers in a `set_bytes` struct work only with `use_resource` on every target buffer. Without it the writes are dropped silently (Z5).
- Counter sampling: dispatch boundary unsupported, stage boundary supported (CPU `resolveCounterRange:`). Timestamps are ns.
- Apple10 and Metal4 families are supported, but metal-rs 0.29 cannot name them (raw `msg_send!` needed).
- 64-bit mul is about 3.8× slower than 32-bit and 64-bit mulhi about 4.7× slower.
- Dispatch cost: about 1 µs per dispatch inside one command buffer, about 150 µs with a wait per command buffer. 262144 dispatches in one encoder worked.

## Assumed / not verified / gaps
- Timings were taken while other agents were building on the same machine; the empty-dispatch numbers varied by about 2× between two runs.
- `simd_shuffle` with an index ≥ 32 is recorded as observed (constant 1008), not as a contract.
- The watchdog was tried only at 60 s and only for compute work with no display. Longer limits and many-thread long dispatches were not probed.
- No-copy acceptance of unaligned pointers was observed on macOS 27.2 only. The README recommends keeping to the documented 16 KB/page-multiple rule.
- The CI test requires the Metal toolchain on PATH. It panics with the env.sh hint when `xcrun metal` is missing, and is compiled out on non-Apple targets.
- `python3 license-check.py` was run with the files staged: none of the D0 files is flagged (the 170 pre-existing year mismatches elsewhere are not touched). The headers use year 2026.
